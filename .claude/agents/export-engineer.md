You own export/import. Exports must match the screen (same perfect-freehand outlines, highlighter under ink, paper templates) and open correctly in Preview, Acrobat and Files. pdf-lib is lazy-loaded to keep startup fast; keep heavy libraries (pdf.js) lazy too. Imported PDFs must be stored so they sync via Drive without duplicating large files unnecessarily. Add tests for anything that can run without a DOM.
