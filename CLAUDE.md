# Noteboard

Production-grade handwriting & note-taking app for **iPadOS** (GoodNotes / Drawboard class) with best-in-class file and folder organization as the differentiator.

## Stack
- Swift 6 (strict concurrency), SwiftUI, iPadOS 18+ deployment target
- PencilKit (ink), PDFKit (PDF), SwiftData (library index), CloudKit / iCloud Drive (sync), Vision (handwriting search), Core Spotlight
- Xcode project generated by **XcodeGen** from `project.yml` — never commit `*.xcodeproj`; edit `project.yml` instead
- No third-party dependencies without an entry in `docs/ARCHITECTURE.md` -> "Dependencies"

## Layout
```
App/                         iPad app target (SwiftUI scenes, navigation, composition root)
Packages/NoteboardKit/       Local Swift package, one module per feature area
  Sources/NoteboardCore      Models, document package format, shared utilities (no UI)
  Sources/NoteboardLibrary   Folders, tags, smart folders, trash, search, SwiftData index
  Sources/NoteboardCanvas    PencilKit canvas, tools, page templates
  Sources/NoteboardPDF       PDF import/render/export
  Sources/NoteboardSync      iCloud document storage, conflicts, backups
  Tests/                     Swift Testing unit tests per module
UITests/                     XCUITest flows
docs/                        ARCHITECTURE.md, ROADMAP.md
.claude/agents/              Project subagents (see below)
```
Dependency direction: `App -> Library/Canvas/PDF/Sync -> Core`. Feature modules do not import each other.

## Commands (macOS with Xcode 16+ required)
```bash
brew install xcodegen
xcodegen generate                          # creates Noteboard.xcodeproj
open Noteboard.xcodeproj
cd Packages/NoteboardKit && swift test     # package unit tests (non-UIKit parts)
xcodebuild test -scheme Noteboard -destination 'platform=iOS Simulator,name=iPad Pro 13-inch (M4)'
```
The current dev machine is Windows with no Mac and no paid Apple Developer account. Code is written here; CI on GitHub Actions (`macos-15`) builds it.

### Running on the iPad: Swift Playgrounds (primary loop)
```bash
powershell -ExecutionPolicy Bypass -File scripts/build-playground.ps1
```
This merges `App/` and every `NoteboardKit` module into one module at `Playground/Noteboard.swiftpm/Sources/` (gitignored) and zips it. The user opens it in Swift Playgrounds on their iPad Pro. Consequences for all code:
- **No duplicate file names and no duplicate internal/private-at-file-scope type names across modules** — they collide when merged (the script fails on duplicate file names).
- Must compile in Swift 5 language mode on iOS 17 too (Playgrounds uses tools 5.9); avoid Swift-6-only syntax.
- No Info.plist / entitlements in Playgrounds: iCloud, document types and multi-window are unavailable there; guard features so the app still runs without them.
- Never edit files under `Playground/Noteboard.swiftpm/Sources/` — they are regenerated.

## Rules
- File system (`.noteboard` packages) is the source of truth; SwiftData is a rebuildable index.
- No file I/O on the main actor. All writes atomic. Every format/schema change needs a version bump, migration, and fixture test.
- Destructive library actions go to Trash or are undoable.
- User-facing strings via `String(localized:)`; every interactive view has accessibility labels.
- Tests use Swift Testing (`@Test`, `#expect`).
